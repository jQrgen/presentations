stormtest demo
Demo, not mainnet. This is a private stormtest chain mined by 4 local miners, each on its own node, on one machine. The nodes are connected through an artificial ~1 s network delay, so miners often find subblocks in parallel on the same parent. That makes the DAG branch, and the next subblock merges the branches by listing every tip as a parent. When the DAG holds k−1 = 39 subblocks, the next summary block (the 40th) closes it. Subblocks left out become uncles that the following summary block includes. None of this is live Nexa mainnet data.
The paper: Tailstorm: A Secure and Fair Blockchain for Cash Transactions by Keller, Glickenhaus, Bissias and Griffith, peer-reviewed at AFT 2023 (arXiv).
Tailstorm terms, explained
Subblock
A small block that a miner finds with a share of the proof of work. Subblocks carry transactions and arrive every few seconds here. They are the circles on this page, coloured by the miner that found them.
Summary block
The block that closes a round. When the DAG holds k−1 subblocks, the next block found is a summary block, which commits to all of them and starts a fresh DAG. Summary blocks are the gold squares, and their height is the chain height.
DAG
Short for directed acyclic graph. Instead of one straight chain, a subblock may point back to several parents, so the blocks form a graph that branches and rejoins but never loops back.
k
How many blocks make up one round: k−1 subblocks plus the summary block. This demo uses k = 40. Nexa mainnet is configured with k = 120.
Tip
A subblock that no other subblock builds on yet, i.e. the current end of a branch. The newest one glows as the DAG tip.
Branch and merge
When two miners find a subblock on the same parent at nearly the same moment, the DAG branches. The next subblock lists every tip as a parent, which merges the branches (marked ⋈). In a normal single-chain blockchain one of those blocks would be thrown away.
Uncle
A valid subblock that missed the summary block it was meant for, usually because the round was already full when it arrived. Instead of being thrown away, it is carried into the next round, and the following summary block includes it. Uncles count towards that round's k−1. They are drawn with a dashed red outline and a U.
Width and depth
Width is the largest number of subblocks found side by side (in parallel) in one DAG, and depth is the length of its longest path. A wider DAG means more parallel mining. A DAG with width 1 is a plain chain.
Stormtest
A private Nexa test network with Tailstorm switched on. It is used only for this demo and isn't mainnet. On mainnet, Tailstorm is implemented but its activation is still pending.
