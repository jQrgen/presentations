stormtest demo
Demo, not mainnet. This is a private stormtest chain mined by a single local miner (one subblock every ~2–3 s). It shows how Tailstorm works: subblocks form a DAG on top of the last summary block, and when the DAG has k−1 = 39 subblocks the next summary block (the 40th) closes it. Because there is one miner, the DAG is mostly a single chain; with competing miners it would branch. None of this is live Nexa mainnet data.
